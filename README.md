# خلف الإجابة — Behind the Answer

لعبة متصفح عربية تفاعلية تكشف العمل البشري والبنية المادية خلف أنظمة الذكاء الاصطناعي، من استخراج المواد والتصنيع ومراكز البيانات إلى تجهيز البيانات والتقييم البشري والتشغيل ثم واجهة المحادثة.

## التشغيل

اللعبة كلها موجودة في ملف واحد: `index.html`.

لا توجد عملية بناء، ولا Backend، ولا قاعدة بيانات، ولا حزم خارجية. يمكن فتح `index.html` مباشرة في المتصفح.

لتشغيلها محليًا عبر خادم ثابت اختياري:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## النشر

المشروع مناسب مباشرة لـ GitHub Pages وأي استضافة ملفات ثابتة. ملف `index.html` وحده يحتوي HTML وCSS وJavaScript اللازمين للعبة.

## التخزين والخصوصية

لا ترسل اللعبة أي بيانات إلى خادم. التقدم وإعدادات الوصول تحفظ محليًا فقط باستخدام `localStorage` داخل متصفح المستخدم، ويمكن مسحها من إعدادات اللعبة.

## قابلية الوصول

- تصميم responsive للهاتف والكمبيوتر.
- دعم لوحة المفاتيح.
- وضع تباين مرتفع.
- تكبير النص.
- تقليل الحركة.
- عدم الاعتماد على اللون وحده في الإشارات.
- المحتوى الحساس غير تفصيلي ولا يتضمن صورًا صادمة.

## منطق اللعبة

تستخدم اللعبة state machine ومسار Branch-and-return. قرارات اللاعب تغير خمسة مؤشرات داخلية وتقرير النهاية، لكن القصة تعود بعد كل قرار إلى المسار الرئيسي حتى تظل التجربة قابلة للصيانة والتطوير.

المؤشرات الداخلية هي:

- ضغط الإنتاج.
- تكلفة الشركة.
- عبء العامل.
- جودة الناتج.
- ظهور العمل البشري.

لا توجد نهاية «صحيحة» أو «خاطئة». الهدف هو إظهار كيف تتوزع التكلفة والمخاطر والعمل والسلطة عبر سلسلة إنتاج الذكاء الاصطناعي.

## الدقة التقنية

تفصل اللعبة بين بناء النظام سابقًا وبين ما يحدث عند استخدامه. التعدين وتصنيع المعدات وتجهيز البيانات والتدريب والتقييم لا يعاد تنفيذها عند كل Prompt؛ بينما يعتمد توليد الإجابة عند الطلب على النموذج والبنية الحاسوبية والشبكات والخدمات التي بُنيت وشُغلت مسبقًا.

الشخصيات والشركات والأرقام داخل اللعبة خيالية ومركبة، ولا تمثل سلسلة توريد شركة أو نموذج بعينه.
