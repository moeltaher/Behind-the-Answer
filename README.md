# Behind the Answer — خلف الإجابة

لعبة متصفح تفاعلية تكشف العمل البشري والبنية المادية خلف أنظمة الذكاء الاصطناعي، من المواد والتصنيع ومراكز البيانات إلى تجهيز البيانات والوسم والتدريب والتقييم والتشغيل ثم واجهة الاستخدام.

## التشغيل

المشروع Static بالكامل: لا Backend، لا قاعدة بيانات، لا Build step، ولا مكتبات خارجية. لأن الكود يستخدم ES modules، شغّل خادم ملفات محليًا أثناء التطوير:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## بنية المشروع

```text
index.html
css/
  variables.css
  base.css
  layout.css
  components.css
  scenes.css
  accessibility.css
  responsive.css
js/
  app.js
  core/
  data/
  components/
  scenes/
docs/
```

- `js/core/`: الحالة، التخزين المحلي، المقاييس، التنقل، الصوت، دفتر السلسلة وقابلية الوصول.
- `js/data/`: محتوى المهام والبيانات التي يمكن تعديلها دون المساس بمحرك اللعبة.
- `js/components/`: عناصر مشتركة مثل HUD، التقدم، الـabstraction والحوارات.
- `js/scenes/`: مرحلة مستقلة لكل جزء من رحلة اللعبة.
- `css/`: فصل المتغيرات والأساس والتخطيط والمكونات والمشاهد والوصول والـresponsive.
- `docs/`: التصميم السردي والمنهجية والملاحظات التقنية.

## الخصوصية

لا ترسل اللعبة بيانات إلى أي خادم. التقدم والإعدادات تحفظ فقط في `localStorage` داخل المتصفح ويمكن حذفها من إعدادات اللعبة.

## الدقة التقنية

تفرق اللعبة بين بناء النظام سابقًا وبين الاستدلال عند الاستخدام. التعدين والتصنيع وتجهيز البيانات والتدريب لا تتكرر مع كل Prompt.
