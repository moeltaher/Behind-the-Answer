# Technical Notes

- التطبيق نفسه HTML/CSS/JavaScript فقط.
- يستخدم ES modules أصلية في المتصفح، من دون bundler أو خطوة build.
- لا Backend ولا قاعدة بيانات ولا حسابات مستخدمين.
- `localStorage` يحفظ الحالة والإعدادات محليًا وفق البنية الحالية فقط؛ لا توجد migration أو backward-compatibility layer لمخططات أقدم.
- الحقول nullable داخل الحالة المحفوظة تتحقق وفق أشكالها الحالية المحددة، ولا يقبل التخزين أنواعًا عشوائية لمجرد أن القيمة الافتراضية `null`.
- لا توجد تبعيات خارجية مطلوبة لتشغيل اللعبة في المتصفح.
- Playwright تبعية اختبار فقط؛ يثبتها GitHub Actions لتشغيل الرحلة والسيناريوهات البديلة على Chromium ولا يُحمّل للمستخدم النهائي.
- كل مرحلة تفاعلية في `js/scenes/`، والبيانات الثابتة في `js/data/`، والمكونات المشتركة في `js/components/`، والمحرك العام في `js/core/`.
- `tests/static-integrity.mjs` يفحص المراجع والمسارات والملفات والـexports والأصول غير المستخدمة وخريطة المشاهد وحقول الحالة القديمة.
- `tests/css-integrity.mjs` يفحص class selectors وCSS custom properties و`@keyframes` غير المستخدمة.
- `tests/storage-schema.mjs` يثبت قبول مخطط الحالة والإعدادات الحالي فقط ورفض الحقول الزائدة والأشكال المشوهة أو القديمة.
- `tests/smoke.mjs` يختبر الرحلة الكاملة على سطح المكتب والهاتف والحفظ وإعادة التحميل والمسارات البديلة.
