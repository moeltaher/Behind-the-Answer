# Technical Notes

- التطبيق نفسه HTML/CSS/JavaScript فقط.
- يستخدم ES modules أصلية في المتصفح، من دون bundler أو خطوة build.
- لا Backend ولا قاعدة بيانات ولا حسابات مستخدمين.
- `localStorage` يحفظ الحالة والإعدادات محليًا، مع ترحيل محدود للحالات القديمة عند التحميل.
- لا توجد تبعيات خارجية مطلوبة لتشغيل اللعبة في المتصفح.
- Playwright تبعية اختبار فقط؛ يثبتها GitHub Actions لتشغيل رحلة كاملة على Chromium ولا تُحمّل للمستخدم النهائي.
- كل مرحلة تفاعلية في `js/scenes/`، والبيانات الثابتة في `js/data/`، والمكونات المشتركة في `js/components/`، والمحرك العام في `js/core/`.
- `tests/static-integrity.mjs` يفحص سلامة المراجع والبنية، و`tests/smoke.mjs` يختبر الرحلة الكاملة على سطح المكتب والهاتف.
