# Technical Notes

- التطبيق نفسه HTML/CSS/JavaScript فقط.
- يستخدم ES modules أصلية في المتصفح، من دون bundler أو خطوة build.
- لا Backend ولا قاعدة بيانات ولا حسابات مستخدمين.
- `localStorage` يحفظ الحالة والإعدادات محليًا وفق البنية الحالية فقط.
- لا توجد تبعيات خارجية مطلوبة لتشغيل اللعبة في المتصفح.
- Playwright تبعية اختبار فقط؛ يثبتها GitHub Actions لتشغيل الرحلة والسيناريوهات البديلة على Chromium ولا يُحمّل للمستخدم النهائي.
- كل مرحلة تفاعلية في `js/scenes/`، والبيانات الثابتة في `js/data/`، والمكونات المشتركة في `js/components/`، والمحرك العام في `js/core/`.
- `tests/static-integrity.mjs` يفحص المراجع والمسارات والملفات والأصول غير المستخدمة، و`tests/smoke.mjs` يختبر الرحلة الكاملة على سطح المكتب والهاتف والحفظ وإعادة التحميل والمسارات البديلة.
