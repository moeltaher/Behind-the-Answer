# Game Design

الحلقة الأساسية للعبة هي:

`شخص → مهمة → قيد أو حدث → قرار → نتيجة → ناتج تقني مختصر`

تستخدم المراحل مسارات تتفرع عند القرار ثم تعود إلى خط الرحلة الرئيسي. لا يوجد تقييم نهائي أحادي؛ تعرض النتيجة الأبعاد التي أثرت فيها اختيارات اللاعب بصورة منفصلة:

- ضغط الإنتاج.
- تكلفة الشركة.
- عبء العامل.
- جودة البيانات.
- جودة النموذج.
- موثوقية البنية والخدمة.
- جودة دعم المستخدم.

لا يغير قرار مؤشرًا إلا عندما توجد علاقة سببية مفهومة داخل السيناريو. ويظل استكشاف الأدوار والمواد الاختيارية مؤشرًا مستقلًا لا يغير نتيجة القرارات.
